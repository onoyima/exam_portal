System Overview

The Assessment Portal is a secure online examination platform designed for academic institutions. It supports objective (MCQ) exams with live proctoring, practical/VIVA scoring by examiners, and comprehensive security monitoring including webcam recording, fullscreen enforcement, tab-lock, keyboard lockdown, and AI-based proctoring alerts.

Tech Stack

  • Backend: PHP 7.4+ with PDO / MySQL
  • Frontend: Bootstrap 5, JavaScript (vanilla + jQuery)
  • Real-time: WebRTC peer-to-peer for live video/audio streaming
  • Recording: MediaRecorder API → server-side chunked upload (.webm)
  • Security: CSRF tokens, session management, device authorization

User Roles

  • Admin Full system control, user/ exam management, live proctoring, video evidence
  • Examiner Grade practical/VIVA exams, view results
  • Student Take objective exams, view results when permitted

Key Security Features

Fullscreen Enforcement Exam locks browser into fullscreen
Tab Lock Switching tabs counts as a violation
Keyboard Lock F12, PrintScreen, Ctrl+U/C etc. blocked
Webcam Recording Continuous video+audio capture
AI Proctor Automated violation detection
Persistent Lock Locked exams survive logout/relogin

Student Guide

Logging In

  1. Navigate to the Student Login page.
  2. Enter your Username (usually your matric number or assigned username) and Password.
  3. Click Log In. You will be taken to your dashboard.

Dashboard & Exam Cards

Your dashboard shows all exams assigned to you. Each exam card displays:

  • Exam name and scheduled date/time
  • Security badges — icons indicating which proctoring features are active (Fullscreen, Tab Lock, KB Lock, Webcam, Live Monitor, Auto Submit, Browser Check)
  • Status — ACTIVE, NOT STARTED, LOCKED — CONTACT ADMIN, or COMPLETED
  • Locked exams show a padlock icon and a disabled "LOCKED — CONTACT ADMIN" button. Only an admin can unlock it.

Taking an Objective Exam

  1. From your dashboard, click Start Exam or Resume Exam on the exam card.
  2. The exam page loads immediately — no security initialization screen appears. All security features (webcam, fullscreen, AI proctor) start automatically in the background.
  3. Answer questions by selecting the radio button for your chosen option. Use Prev / Next to navigate.
  4. The timer at the top shows remaining time. The exam auto-submits when time expires.
  5. To finish early, click Submit Exam and confirm.

Violations & Locking

Security violations are triggered by:

  • Leaving the browser tab / window
  • Exiting fullscreen mode
  • Pressing forbidden keys (F12, PrintScreen, Ctrl+U/C, etc.)
  • AI proctor detecting suspicious behavior

Each violation shows a red overlay with a 60-second countdown. Click RETURN TO EXAM to continue. After 5 violations, the exam is permanently LOCKED — you cannot proceed and must contact an administrator.

When locked, the exam card on your dashboard shows LOCKED — CONTACT ADMIN. Only an admin can unlock it from the Live Proctoring panel.

Recording & Privacy

During the exam, your webcam video and microphone audio are continuously recorded and streamed to the proctoring server. This serves as:

  • Live monitoring — the admin can view your video in real-time
  • Evidence recording — all footage is saved as .webm files and can be retrieved later as proof if a cheating dispute arises

Recordings are stored securely and can only be downloaded by administrators.

Reviewing Results

If the exam allows score viewing, you can see your results by clicking View Result on the exam card after the exam is completed.

Admin Guide

Student Management

  • Add Student: Fill in name, username, matric number, and password. Unique matric/username enforced.
  • Edit / Delete: Update student details or remove them from the system.
  • Bulk Upload: Upload students via CSV (columns: name, username, matric_no, password).

Question Management

  • Add / Edit / Delete objective questions with options, correct answer, and mark value.
  • Bulk Upload: Upload questions via CSV (columns: question, option_a, option_b, option_c, option_d, correct_option, mark).

Exam Management

  • Create Exam: Set name, type (objective/viva), duration, dates, max attempts, and security flags.
  • Assign Students: Select which students can take the exam.
  • Assign Questions: Select which questions appear in the exam.
  • Assign Examiners: Link examiners to practical/VIVA exams for grading.
  • Activate / Deactivate: Control whether the exam is accessible to students.

Results & Reports

  • View student scores and totals per exam.
  • Download CSV reports for offline analysis.
  • Students with no scores are clearly indicated.

Live Proctoring (admin_live_proctor.php)

The Live Proctoring panel is your command center for monitoring active exams. Access it via the admin sidebar.

Features:

  • Live Video Stream: Click Stream on any active student card to view their webcam feed in real-time via WebRTC. Click Stop to end the stream.
  • Speak to Student: After starting a stream, click Speak to broadcast your voice to the student. Your microphone audio is sent through the same WebRTC connection. Click again to mute.
  • Send Warning: Click Warn to send a popup warning message to the student's screen.
  • Tag Violation: Click Tag to manually increment the student's violation count.
  • Force Submit: Click Submit to immediately end the student's exam, calculate their score, and finalize the attempt.
  • Force Submit All: When filtering by a specific exam, the Submit All button ends and grades every active attempt for that exam.
  • Unlock Student: When a student's exam is locked (after 5 violations), a Unlock Student button replaces Warn/Tag/Speak/Submit. Clicking it resets is_locked = 0 and clears all violations.

Filters: Search by name/matric, filter by exam, sort by activity/violations/name, and toggle between Active and History view.

Video Evidence

Every streaming session is automatically recorded. Chunks are uploaded every 5 seconds and saved as .webm files in uploads/recordings/attempt_{id}/.

To download evidence:

  1. Go to the Video Evidence tab (accessible from this documentation page).
  2. Select the Exam and Date from the dropdowns.
  3. Click Download ZIP. The system compiles all recordings into a single ZIP file.
  4. Inside the ZIP, videos are organized into folders named after each student's matric number.

These recordings serve as irrefutable evidence if a student disputes a cheating accusation.

Chat System

Admins and examiners can communicate via the built-in chat system, send messages, attach media files, and view unread indicators.

Audit Trail

All significant actions (logins, additions, assessments, violations) are logged with timestamps and user details. The admin can view and filter the audit log from the sidebar.

Examiner Guide

Logging In

Log in using your examiner credentials on the Examiner Login page. You will be taken to your dashboard showing assigned exams.

Grading Practical / VIVA Exams

Use the Assess Practical/VIVA page (assess.php) to grade students assigned to you.

  1. Select the Exam from the dropdown.
  2. Search for a student by name, username, or matric number.
  3. When the student is found, their question checklist appears with score options (e.g., 0, 1/4, 1/2, 3/4, 1).
  4. Click any score — it saves instantly via AJAX without needing to press a "Save" button. A green checkmark indicator confirms the save.
  5. Continue scoring all questions. The Save Assessment Data button also exists for a final bulk save.
  6. After saving, the page shows a success message. The scores are stored in the database and can be updated later (re-assessment).

Searching for Students

The search supports:

  • Full name (John Doe)
  • Username (john.doe)
  • Full matric number (2021/123456)
  • Last 4–6 digits of matric (123456)

If a student is not assigned to the selected exam, an error message is shown.

Re-assessment

Searching for a student who has already been graded will load their existing scores. Changing a score updates the record (it does not create a duplicate). The page shows "Second Attempt/Revision" to indicate an update. Only an admin can reset scores to allow a full fresh assessment.

Chat with Admin

Examiners can use the chat system to communicate with administrators, share files, and coordinate during exam sessions.
