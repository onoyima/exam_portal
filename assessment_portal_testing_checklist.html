Assessment Portal Testing Checklist

Comprehensive QA checklist for verifying all features and workflows before deployment.

Date:   |   Tested by: ______________________

1. Environment Setup

PHP, MySQL, and web server are installed
Database imported from provided SQL files
db.php configured with correct credentials
App loads in browser without errors

2. User Roles & Access Control

Admin can log in and access all admin pages
Examiner can log in and access examiner dashboard
Unauthorized users cannot access protected pages
Session expires on logout

3. Student Management

Add a new student (unique matric/username enforced)
Edit student details and verify update
Delete a student and verify removal
Bulk upload students via CSV
Error shown for invalid/malformed CSV

4. Question Management

Add, edit, and delete questions
Bulk upload questions (CSV with partial marks)
Error shown for invalid/malformed question CSV

5. Exam Management

Create a new exam and assign questions/students
Edit exam details, add/remove questions/students
Activate/deactivate exam and verify access
Assign/remove examiners from exams

6. Assessment Workflow

Examiner searches for a student assigned to an exam
Student name, matric number, and exam name are displayed
Complete and submit assessment; verify scores saved
Re-assess updates scores, not duplicates
Admin resets a student's scores; reassessment possible
Searching for a non-assigned student shows error message

7. Results & Reporting

Admin/examiner can view student scores and totals
Download report as CSV; verify structure and data
Students with no scores are clearly indicated

8. Chat System

Send and receive messages between admin and examiner
Attach media files in chat
Group chat (if available) works as expected
Chat notifications and unread indicators work

9. Audit Trail

Actions (login, add, assess, etc.) are logged
Admin can view and filter audit logs

10. UI/UX & Responsiveness

Footer is sticky on all pages
Dark/Light mode toggle works everywhere
Layout is responsive on mobile, tablet, desktop
Accessibility: alt text, keyboard nav, color contrast

11. Security

Sessions expire on logout
SQL injection attempts are blocked
XSS attempts are blocked (inputs escaped)
File uploads restricted to allowed types

12. Error Handling

Invalid/missing form data shows clear error
Database errors show user-friendly messages
404/500 error pages are handled gracefully

13. Performance

Bulk uploads (students/questions) are fast
Multiple users can assess at the same time
